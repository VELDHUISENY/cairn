# Cairn

## Goal
Cairn is my personal site at `cairn.summitlab.dev`: a hub with one "door" per subject I like to explore (movies, local history, space) and a showcase of my Avans coursework. Each subject is its own small world with its own design. I build it myself using lain HTML, CSS and JS, and it grows with every module, adding back-end in semester 2. Like a cairn on a trail, it grows one stone at a time.
